Changes made by Zenkai
----------------------
- The 28 presets were copied as hair codes (unchanged) into source/presets.json, which
  is the preferred form for modifying them. Preset 5 (Krillin, bald) was left out.
- Each preset became a Zenkai hair-catalog entry (data/zenkai_dmz/zenkai_hair_styles/),
  grouped in the "DragonMineZ" folder of the Hair tab. Zenkai converts the code into a
  model at runtime with its own reader (no DragonMineZ code is included).
- Display names (assets/zenkai_dmz/lang/) and SSJ4 fallbacks follow DragonMineZ's
  HairPresets (shared SSJ4 styles: default, Trunks, Gohan).
Regenerated with tools/dmz_presets/ (extract_presets.py + gen_dmz_presets.py) in the
Zenkai repository.
