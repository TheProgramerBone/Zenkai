# Pack de peinados de ejemplo / Example hair pack

**ES** — Copia esta carpeta entera a `<juego>/zenkai/hair_packs/hair_pack_ejemplo/` (Zenkai la carga sola como pack
de datos y de recursos), o empaquétala en un zip como datapack + resource pack. Después `/reload` y F3+T: aparece una
carpeta "Pack de ejemplo" en la pestaña Pelo con tres peinados (uno DMZ con variante SSJ, uno DBC y "El original": el rectángulo blanco de cubos que fue el pelo de Zenkai durante mucho tiempo, conservado como ejemplo de peinado `geo`).
Las reglas completas están en `ADDONS.md` §1b. Los códigos son PROPIOS; se generan con `tools/gen_example_hair_pack.py`.

**EN** — Copy this whole folder to `<game>/zenkai/hair_packs/hair_pack_ejemplo/` (Zenkai loads it as a data and
resource pack), or zip it as a datapack + resource pack. Then `/reload` and F3+T: a "Pack de ejemplo" folder shows up in
the Hair tab with three styles (a DMZ one with an SSJ variant, a DBC one, and "El original": the plain white cube rectangle that was Zenkai's hair for a long time, kept as a `geo` example). Full rules in `ADDONS.md` §1b. The codes are
ORIGINAL; generated by `tools/gen_example_hair_pack.py`.

```
pack.mcmeta
data/ejemplo/zenkai_hair_packs/mi_pack.json              <- el manifiesto / the manifest
assets/ejemplo/textures/gui/hair_folders/mi_pack.png     <- ícono de la carpeta / folder icon
```
